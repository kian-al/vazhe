# Open dictionary attribution

`dictionary-part-*.b64` (gzip-compressed, base64-encoded JSON) is an adapted subset of English Wiktionary contributed by
English Wiktionary contributors, extracted by Kaikki/wiktextract (Tatu Ylonen et al.).

- Source: https://kaikki.org/dictionary/English/
- Upstream: https://en.wiktionary.org/

- Each entry retains a source-page link, attribution and license.
- Changes: selected direct Persian translations, normalized Arabic/Persian letters and optional vocalization marks,
  deduplicated entries, selected one part of speech, removed examples/quotations.
- No endorsement is implied. This subset is redistributed under CC BY-SA 4.0.
- Download the adapted data at /api/dictionary?download=1. Large downloads are
  server-generated, not included in the browser bundle.

The data is community-maintained, not professionally reviewed. Multiple
translations can correspond to different senses. No machine translation or AI
content has been fabricated to fill gaps. This release does NOT include Tatoeba
sentences or FrequencyWords-derived ranks. Application source and data licenses
are separate.
