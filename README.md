# واژه

وب‌اپ فارسی‌محور و راست‌به‌چپ برای یادگیری واژگان انگلیسی. رابط کاربری بر پایهٔ بازطراحی تأییدشده با پوستهٔ ثابت **Grove (گرُو)** پیاده شده است؛ اول دسکتاپ و بعد موبایل.

## اجرا

نیازمندی: Node.js 20.9 یا جدیدتر.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # تایپ‌چک + تست‌ها + next build
```

## مسیرها

| مسیر | کار |
| --- | --- |
| `/` | مرور: مطالعهٔ آزاد (همیشه باز) جدا از مرور زمان‌بندی‌شده |
| `/words` | همهٔ واژه‌های شخصی، جست‌وجو و فیلتر وضعیت/مرحله؛ دسکتاپ دوستونه |
| `/word/[wordId]` | جزئیات واژه، افزودن/برداشتن از صف، حذف با تأیید |
| `/search` | جست‌وجوی انگلیسی/فارسی، پیشنهاد املایی، افزودن دستی |
| `/queue` | صف بدون سقف (FIFO)، قابل جست‌وجو |
| `/library` ← `/library/[bookId]` ← `/library/[bookId]/[chapterId]` | افزودن فصل یا کتاب؛ تکراری‌ها خودکار رد می‌شوند |
| `/batch` | دستهٔ فعال: ظرفیت ۱۰۰، توزیع مرحله‌ها، قفل دستهٔ بعدی |
| `/study?scope=all\|queue\|batch&w=` | مطالعهٔ آزاد با کارت برگردان؛ Space/Enter و کلیدهای ۱–۴ |
| `/extension` | پیش‌نمایش وب افزونهٔ مرورگر (افزونهٔ نصب‌شده نیست) |

## قواعد محصول که رعایت شده‌اند

- مطالعهٔ آزاد همهٔ واژه‌های شخصی را پوشش می‌دهد، سقف ندارد و موعد، مرحله یا وضعیت را تغییر نمی‌دهد.
- دسته حداکثر ۱۰۰ واژه؛ دستهٔ بعدی تا گذر همهٔ اعضا از مرحلهٔ ۵ قفل است، ولی دیدن واژه‌ها و مطالعهٔ آزاد قفل نیست.
- حذف تکرار بر پایهٔ صورت نرمال‌شدهٔ واژه؛ برداشتن از صف واژه را از فهرست حذف نمی‌کند.

## نمایشی یا هنوز تصمیم‌گیری‌نشده

- **FSRS وصل نیست**؛ هیچ موعد مرور ساختگی نشان داده نمی‌شود.
- **قانون پیشروی بین مرحله‌های ۱ تا ۵** و **قانون ورود از صف به دسته** هنوز تعیین نشده‌اند و برنامه خودش آن‌ها را اجرا نمی‌کند.
- متن «مربی» پس از «فراموش کردم» ثابت است و برچسب نمایشی دارد؛ هوش مصنوعی و نمره‌دهی وصل نیست.
- واژه‌نامه فقط ۱۰۴ مدخل نمونهٔ دست‌نویس است (`src/lib/dictionary.ts`) پشت رابط `DictionaryProvider`؛ منبع نهایی و مجوزش تعیین نشده.
- کتابخانه فقط دو اثر مالکیت عمومی (پروژهٔ گوتنبرگ) با فهرست واژهٔ گزیده دارد؛ متن کتاب بازنشر نمی‌شود.
- داده‌ها فقط در `localStorage` همین مرورگر (`vazhe.local.v2`) ذخیره می‌شوند؛ حساب کاربری و همگام‌سازی سرور نداریم. دادهٔ نسخهٔ قبلی خودکار منتقل می‌شود.

## کیفیت

- `npm test`: تست‌های منطق واژه‌ها (صف، حذف تکرار، مطالعهٔ آزاد، قفل دسته، جست‌وجو، مهاجرت داده).
- QA با Playwright روی سرور محلی (`npx next start -p 3100`):
  - `node scripts/qa/visual.mjs 1440` (و 1366، 390، 360): اسکرین‌شات در `.qa/v2/` و گزارش سرریز افقی/خطای اجرا.
  - `node scripts/qa/functional.mjs`: افزودن به صف، ماندگاری، تکرار، برداشتن از صف، افزودن فصل، دور کامل مطالعهٔ آزاد.

## ساختار

- `src/design/tokens.ts` — توکن‌های طراحی (Grove پیش‌فرض و ثابت)
- `src/lib/` — منطق خالص واژه‌ها، واژه‌نامهٔ نمونه، رابط ارائه‌دهندهٔ واژه‌نامه
- `src/components/` — پوستهٔ برنامه، store محلی، اجزای رابط و فهرست مجازی واژه‌ها
