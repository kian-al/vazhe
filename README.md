# واژه — نمونهٔ اجرایی محلی

یک برش عمودیِ قابل اجرا برای وب‌اپ یادگیری واژگان فارسی‌محور. ظاهر، لحن فارسی، RTL و رفتار واکنش‌گرا از تازه‌ترین نمونهٔ تأییدشده در `/data/.agent-service/files/.../واژه — نمونهٔ تعاملی طراحی(1).html` پیروی می‌کنند؛ فایل تأییدشده دست‌نخورده مانده است.

## اجرا

نیازمندی: Node.js 20.9 یا جدیدتر.

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کن.

## آنچه اکنون کار می‌کند

- رابط فارسی راست‌چین با پوسته‌های Grove، Orbit و Folio؛ نوار کناری دسکتاپ و ناوبری پایین موبایل.
- فهرست کامل واژه‌های شخصی، جزئیات واژه، جست‌وجوی فارسی/انگلیسی با پیشنهاد املایی و افزودن دستی.
- صف قابل جست‌وجو، حذف تکرار بر پایهٔ صورت نرمال‌شدهٔ واژه و مطالعهٔ آزادِ همه/صف/یک واژه.
- کارت پرسش ← نمایش معنی و مثال ← چهار امتیاز خودارزیابی.
- ذخیرهٔ محلی در `localStorage` همین مرورگر.
- قواعد دامنه و تست برای جلوگیری از اثر مطالعهٔ آزاد بر برنامهٔ مرور و مرحلهٔ دسته.

## مرزهای نسخهٔ محلی

- داده‌های واژه‌نامه فقط نمونه‌اند؛ جست‌وجوی زنده، صوت تلفظ و محتوای کتاب دارای مجوز وصل نیست.
- `localStorage` ذخیره‌سازی شخصیِ همین مرورگر است، نه پایگاه دادهٔ سروری، پشتیبان‌گیری یا همگام‌سازی امن چندکاربره.
- ورود کاربر، API، تولید راهنمای هوش مصنوعی و ارزیابی معنایی پیاده‌سازی نشده‌اند؛ رابط خروجی ساختگی یا اتصال‌نما نشان نمی‌دهد.
- مرور زمان‌بندی‌شده/FSRS هنوز جداگانه پیاده نشده است. امتیازهای مطالعهٔ آزاد فقط در همان جلسه شمرده می‌شوند و موعد یا مرحله را تغییر نمی‌دهند.
- پیشروی دقیق میان پنج مرحله هنوز تصمیم‌گیری نشده؛ این اپ مرحله را جلو نمی‌برد و شروع دستهٔ بعدی را فعال نمی‌کند. ظرفیت هدف دسته حداکثر ۱۰۰ واژه است.
- سرویس احراز هویت، پایگاه داده و استقرار روی Vercel هنوز متصل نشده‌اند. مخزن GitHub فقط برای نسخه‌برداری کد است و به‌تنهایی ماندگاری داده‌های کاربر ایجاد نمی‌کند.

## فرمان‌های بررسی

```bash
npm run typecheck
npm test
npm run build
```

## گام‌های بعدی

1. تصمیم دربارهٔ مرحله‌های پنج‌گانه و رابطه‌شان با برنامهٔ مرور FSRS.
2. انتخاب مخزن/سازمان GitHub، روش احراز هویت و پایگاه دادهٔ دارای ماندگاری سمت سرور.
3. انتخاب منبع واژه‌نامه و مجوز/محدودیت بازنشر کتاب‌ها.
4. پیاده‌سازی مرور زمان‌بندی‌شده با `ts-fsrs` پس از تصمیم محصول، نه پیش از آن.
5. اتصال امن راهنمای هوش مصنوعی از سمت سرور، با اعتبارسنجی پاسخ و حالت‌های بارگذاری/خطا/تلاش دوباره.
6. افزودن رابط extension مستقل (حدود ۳۶۰–۴۰۰ پیکسل) و سپس برنامهٔ native iOS؛ نمای وب جایگزین extension نصب‌شده یا iOS بومی نیست.
7. آزمون‌های end-to-end، بررسی دسترس‌پذیری، همگام‌سازی و راهبرد مهاجرت داده.
